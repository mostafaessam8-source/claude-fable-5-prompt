# Zulfi Railway Station – interactive management presentation

Static HTML presentation (no build step, no external libraries) generated from `Zulfi_Station_WBS_CBS_Schedule.xlsx`.
Published by GitHub Pages at `/zulfi-presentation/`.

Slides follow the workbook sheets: Dashboard → WBS & CBS → 26-Month Schedule (Gantt, S-curve, cash-flow matrix) → Assumptions & Weightages → Scenario summary.

* Project start date (default 25 Oct 2026) and every activity's start/finish are editable; Gantt, S-curve, milestones and cash flow recalculate live.
* Linking modes control how dependent activities move. Weightages on the Assumptions slide are editable too.
* Controls: Back / Next (← →), Full screen / Exit (F), Print (all slides), filters, click-for-details drawer.
* `data.js` holds the extracted workbook data; `js/engine.js` reproduces the Excel cash flow exactly.

## Site layout
* `index.html` – guide that explains each Excel sheet and offers the downloads.
* `presentation.html` – the interactive deck (deep links: `presentation.html#6` opens slide 6).
* `downloads/Zulfi-Presentation-Offline.html` – single-file offline copy, generated by `python3 build_offline.py` (the Pages workflow regenerates it on every deploy). Re-run the script and commit after editing the deck.
* `downloads/Zulfi_Station_WBS_CBS_Schedule.xlsx` – the source workbook.

## Project Director brief + financial snapshot (Arabic / English) – `director.html`
Five slides for the new project director and the Association meeting: overview & budget, Phase 1 scope & milestones, Phase 2 scope & dependencies, integrated timeline (with a Phase 2 start scenario test) and a one-page financial / cash-flow snapshot with the NTP contract note. Figures are live from the model (`js/slides-director.js`, `css/director.css`); offline copy `downloads/Zulfi-Director-Brief-Offline.html`.

## Management update deck (Arabic / English) – `management.html`
SAR-template deck rebuilt from the "عرض مستجدات مشروع محطة قطار الزلفي" PowerPoint: cover, agenda (side menu), introduction, about the project, current status, first-six-months cash flow, next steps and thank-you – plus the **Milestones**, **Why Phase 2 starts with Phase 1** and **Cash flow & S-curve** slides of the main deck (live model, same scenario controls).
* Language switch (toolbar): the whole deck flips between Arabic (RTL, default) and English; edits are stored per language.
* **Edit** mode: click any text to change it (saved in the browser), drag the milestones, **Delete this slide** / **Restore deleted slides**. **Reset** restores everything.
* Cash flow slide: Monthly / Quarterly / Half-year / Yearly + **Export Excel** (SAR-styled, Arabic sheet when the deck is in Arabic).
* Files: `management.html`, `css/mgmt.css`, `js/i18n.js` (Arabic dictionary for the reused slides), `js/slides-mgmt.js` (the new slides), `js/mgmt-shell.js`, `assets/` (SAR logo and photos from the PowerPoint).
* Offline copy: `downloads/Zulfi-Management-Update-Offline.html` (single file, images embedded) – generated by `python3 build_offline.py` together with the main offline copy.
* **PowerPoint export** (toolbar button, both decks): writes the current slides – with your edits, language and scenario – as an editable .pptx (native shapes, text boxes and pictures, SAR colours; fonts Diodrum Arabic / 29LT Kaff are referenced by name). Code: `js/pptx.js`.
