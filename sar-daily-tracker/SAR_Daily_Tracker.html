Cloud sync

Keeps your tracker in a private GitHub repository of your own, so the same data opens on any device. One-time setup:

  1. On GitHub, create a new private repository (any name, e.g. sar-tracker-data).
  2. GitHub → Settings → Developer settings → Fine-grained tokens → generate a token with access to only that repository and the permission Contents: Read and write.
  3. Enter both below — once on each device you use.

The token is stored only in this browser and is sent only to GitHub.
