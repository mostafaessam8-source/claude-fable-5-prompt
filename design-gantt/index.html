What the chart shows

  • Baseline line (grey): baseline submission → baseline approval of the design stage.
  • Actual / Forecast line: actual submission → SAR review (teal); submitted and still with SAR (amber hatching, up to the data date); forecast re-submission → forecast approval (light hatching); the current plan dates (violet hatching). The letter on the bar is SAR's review code.
  • Project / element rows roll their design stages up; open them with the outline buttons in Excel or the arrows here.

Rules (same as the Tracker's own formulas)

    Notes

    • Only the Tracker sheet is read; formulas are not recalculated, the cached values and dates in the file are used. Save the workbook in Excel before uploading so those values are current.
    • Every other sheet in the workbook is returned untouched; the Gantt chart sheet is replaced each time you generate a new one.
    • The chart is a picture of the dates at the moment you generate it. After changing dates in the Tracker, upload the workbook again.
